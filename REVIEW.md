# Clude Code Review
This file serves for the sole purpose of guiding claude code when making review, whther that be by claude-code-rewiew or by explicit mentioning @claude on PR, comments, etc.

## General guide
- Never change something by yourself, just add comments
- Check for Golang standard and best practices. If you find something off, flag it
- Check for Golang gotchas. If you find something that could not work as expected, flag it
